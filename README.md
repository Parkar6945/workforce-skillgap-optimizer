# Problem #6: Workforce Capacity & Skill Gap Optimizer

## Overview
An AI workforce intelligence system designed to map employee competencies across teams, forecast skill deficits against active project deadlines, and formulate automated hiring/upskilling strategies.

### Features
- **Project Feasibility Scanner**: Benchmarks current qualified skill pools against pipeline roadmaps.
- **Competency Gap Classification**: Categorizes deficits into Critical Shortages, Moderate Gaps, and Surplus talent pools.
- **Upskilling Pool Discovery**: Identifies intermediate candidates ready for accelerated promotions or bootcamps.
- **Interactive Web Interface**: Live charts, bottleneck alerts, and actionable HR recommendations.

## Running the Application
```bash
python main.py
```
